# Hello World

A small static Hello World website — plain HTML, CSS and JavaScript, no build step.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page markup |
| `style.css` | Styling, light/dark theme tokens |
| `script.js` | Greeting cycler, live clock, theme toggle |

## Run it locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Features

- Multilingual greeting that cycles on button click
- Live clock
- Light/dark theme toggle that remembers your choice
- Responsive layout
