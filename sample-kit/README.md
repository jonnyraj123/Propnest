# Sample kit

Premium animated "after" samples for cold outreach, built from a small lead file.

1. Put the lead's photos in `leads/<id>/` and write `leads/<id>.json` (copy an existing one).
2. Run `python3 make.py leads/<id>.json`.
3. Send `out/<id>/before_after.gif` (email) or `before_after.mp4` (Instagram/WhatsApp).

Templates: `barber`. Planned: `nails`, `cleaning`, `bakery`.
